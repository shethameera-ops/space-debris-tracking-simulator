# Space Debris Tracking & Magnetic Capture Simulation

A simulation study on tracking orbital space debris and modeling magnetic capture as an active debris removal (ADR) concept.

## Overview
This project simulates the tracking of space debris objects and models a magnetic capture mechanism as a candidate active debris removal strategy, exploring the feasibility and dynamics of magnetically-assisted rendezvous and capture.

## Scope
- Orbital propagation and tracking of debris objects
- Magnetic field / dipole interaction modeling for capture dynamics
- Feasibility analysis of magnetic capture as an ADR method

## Tools
- MATLAB/Octave (orbital dynamics, magnetic interaction modeling)
- Python (supporting analysis/visualization)
